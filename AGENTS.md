# Repository Working Instructions

Read `docs/REPOSITORY-STATUS.md`, `docs/BUILD_IDENTITY.md`, and `docs/CLASSROOM-PROVENANCE.md` before changing the room or producing a build.

Use issue-first task branches and draft PRs for review. Do not merge, deploy, dispatch workflows, change Pages settings, or write shared graphics catalogs without explicit authorization. Keep draft checks local to control Actions cost.

Keep source classroom photos and student data outside this repository and review packages. Use generic procedural textures. Preserve historical artifacts and evidence; distinguish regenerated exports from unrebuilt or untested formats. Keep the standalone controls and optional activity example separate from reusable classroom geometry.

Follow the full build identity contract and authored Title Case for new or touched user-facing titles. Run focused geometry, collision, asset and browser checks for classroom changes. Record unavailable native runtime checks honestly.
