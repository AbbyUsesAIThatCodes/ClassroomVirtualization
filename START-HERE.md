# Welcome to your virtual classroom

1. Open `Classroom-Walkthrough.html` in a current browser. It works offline.
2. Select **Walk into the classroom**. Use WASD or arrow keys to move and drag to
   look; Escape releases the mouse. Phones have an arrow pad.
3. Try **Room overview**, or use the viewpoint menu to visit the printer corner.
4. Open **Scene → Place a lever example** to see a separate activity on a bench.

For Godot, import `godot/project.godot` and press F5. To reuse just the room,
copy `godot/classroom/` into your own project and instance `classroom.tscn`.

For other engines, import `public/assets/classroom.glb`; the companion JSON
contains collision boxes and attachment points. See `docs/INTEGRATION.md`.

This is First Light v0.1.0: a stylized reconstruction from your photos, with
estimated dimensions. Source, verification details and calibration notes are
included. The GitHub initialization/PR step awaits approval as documented in
`docs/REPOSITORY-STATUS.md`.
